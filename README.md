# devops-course-2026

Практические работы по дисциплине «Инструменты DevOps».

## Практическая работа № 5. Удалённый сервер и безопасный доступ. SSH, sudo, UFW, DNS

- `docs/server-setup.md` — конфигурация виртуальной машины `devops-vm`: параметры, сеть, SSH, UFW, снимки состояния.
- `scripts/audit.sh` — скрипт контроля конфигурации сервера.

Запуск аудита на сервере:

```bash
sudo bash scripts/audit.sh
```

Скрипт возвращает 0, если все проверки пройдены, и 1 при наличии расхождений.
